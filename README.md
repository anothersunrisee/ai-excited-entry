# ai-excited-01 — Phoenix of Glass and Fire

An entry for make.fun's **ai-excited-01** bounty: make the AI judge excited.

The image is a phoenix of molten gold and shattered stained glass bursting
upward through a dark storm sky — original art made for this entry. The
program (`main.ts`, Node 22, standard library only) copies `entry.png` to the
grader's output directory.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

- `entry.png` — the image (512×512 PNG, 544 KB)
